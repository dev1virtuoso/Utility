Questions

Define the questions Clef should answer. Each question has a type: Yes/no (noul), Choice, or Score. All questions and options are scored together in a single forward pass.
Notes & limitations
  • Clef is a decision model: it returns probabilities and confidence, not generated text. Confidence measures how concentrated the probabilities are — it is not the chance the answer is correct.
  • Supported inputs: text (state) and images. Images are scored together with the text.
  • Not supported: audio input (Ollama's /v1/systemone currently accepts only text and images); object bounding-box coordinates (Clef is not an object detector).
  • For bounding boxes, use a vision model that outputs coordinates (e.g. moondream / a grounding model); to decide about audio, transcribe it first with a speech model (whisper / SenseVoice), then hand the text to Clef.
